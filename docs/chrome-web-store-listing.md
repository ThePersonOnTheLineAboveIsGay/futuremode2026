## 詳細描述

```
Meet 會議小甜心是 Google Meet 裡的即時會議夥伴：它聽懂討論，在有人前後說法矛盾、明顯離題、有可核對的邏輯問題，
或提出方案／意見值得表態時，主動給出它的判斷與建議——不只是列出雙方論點，而是直接說出自己的看法，
讓討論更快聚焦，最終決定權仍在團隊手上。

【運作方式】
1. 你按下「開始監聽」後，擴充功能擷取你自己的麥克風音訊（需要你核准麥克風權限）。
2. 同時以 Meet 分頁混音音訊作為備援，涵蓋同一場會議中沒有安裝擴充功能的與會者（匿名處理）。
3. 音訊即時傳到你設定的後端伺服器，轉寫成繁體中文逐字稿並比對近期會議脈絡。
4. 偵測到矛盾、離題、邏輯錯誤或值得表態的方案討論時，主動產生提醒。
5. 提醒以浮動卡片顯示在你的畫面上，並可自動貼進 Meet 聊天室，讓沒有安裝擴充功能的與會者也看得到。

【適合對象】
- 遠端產品／工程團隊：決策被口頭改動卻沒人說明原因時，及時指出前後不一致。
- 學生專題／黑客松隊伍：討論容易跳來跳去時，快速把注意力帶回當前決策。
- 會議主持人：AI 負責偵測可疑的前後矛盾，主持人能專心引導討論。
- 跨職能團隊：即使有人沒安裝擴充功能，聊天室仍會出現提醒，所有人都能跟上。

【隱私】
- 只會擷取「你自己」的麥克風聲音；分頁混音只在你按下開始監聽後才會用來備援辨識其他人的發言，且不會指名。
- 音訊與逐字稿只保存在伺服器記憶體中，沒有資料庫或永久儲存，會議結束或閒置一段時間後自動清除。
- 擴充功能不會讀取 Google Meet 內建字幕，也不會回讀既有聊天室訊息。
- 詳細資料處理方式請見隱私權政策。

本專案為開源專案，原始碼與相關文件公開於 GitHub。
```

## 權限用途說明（Developer Dashboard「隱私權作法」/ Permission justification）

Chrome 審核會要求針對 manifest 中列出的每個權限說明用途，以下是可直接複製使用的文字：

| 權限 | 用途說明（英文審核欄位可翻譯使用） |
| --- | --- |
| `offscreen` | 需要在背景（無視覺畫面）持續處理麥克風與分頁音訊串流並維持與後端的 WebSocket 連線；Manifest V3 的 service worker 本身不能直接使用 `getUserMedia`，因此需要 Offscreen Document 承載這段音訊擷取邏輯。 |
| `storage` | 把使用者設定的後端伺服器網址、顯示名稱、語音提醒開關等**只存在使用者本機瀏覽器**（`chrome.storage.local`），下次開啟時記得設定值；不會同步到雲端或傳給開發者。 |
| `tabCapture` | 擷取目前 Google Meet 分頁的混音音訊，作為麥克風以外的備援來源，涵蓋同一場會議中沒有安裝本擴充功能的與會者的發言（僅用於語音轉文字與分析，匿名處理）。 |
| `host_permissions`（`https://meet.google.com/*`） | 擴充功能的所有功能（浮動提醒卡、聊天室自動發送、顯示名稱偵測）都只在 Google Meet 頁面運作，不需要存取其他網站。 |

## 單一用途說明（Single purpose）

```
即時聆聽使用者在 Google Meet 會議中的發言，透過 AI 偵測前後矛盾、離題、邏輯錯誤，並主動提出插話建議，
以浮動卡片與 Meet 聊天室訊息呈現給會議參與者。
```

## 資料使用揭露（Developer Dashboard「Data usage」勾選建議）

以下依目前擴充功能的實際行為建議勾選，實際仍以 Chrome 當時的表單措辭與後端實際部署狀況為準：

- **收集的資料類型**：勾選「音訊 / Audio」（麥克風、分頁混音）；如果後端會依顯示名稱歸屬發言，也勾選「個人識別資訊 / Personally identifiable information」（僅限使用者自願填寫或自動偵測到的顯示名稱）。
- **用途**：勾選「應用程式功能 / App functionality」；**不要**勾選廣告、行銷相關用途（本專案不做廣告）。
- **是否會傳出裝置**：是——音訊與逐字稿會傳到使用者設定的後端伺服器（預設為開發者提供的公用範例後端）。
- **是否販售給第三方 / 用於與核准用途無關的用途**：否。
- **是否使用遠端程式碼（remote code）**：否——所有邏輯都內建在擴充功能套件內，只透過 WebSocket 交換資料，不會動態載入外部 JS。
- 記得勾選「我已閱讀並同意 Developer Program Policies」，並在表單附上 `PRIVACY_POLICY.md` 的公開連結。

## 圖片素材

- **圖示（必填）**：已產生於 `extension/icons/`（16/32/48/128px），已在 `manifest.json` 中設定 `icons` 與 `action.default_icon`。
- **商店主圖 Screenshot（必填，至少 1 張，1280x800 或 640x400）**：需要實際打開 Google Meet 操作擴充功能後截圖（例如浮動提醒卡出現、聊天室收到提醒的畫面），這部分需要人工操作瀏覽器截圖，無法在這裡自動產生——可參考 `README.md` 的「Demo / 展示流程」段落走一次流程再截圖。
- **宣傳小圖／大圖（選填，440x280 / 1400x560）**：非必要，之後有需要可以再另外設計。
